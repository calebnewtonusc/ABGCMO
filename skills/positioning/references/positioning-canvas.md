# Positioning canvas (April Dunford, 10-step)

## 1. Competitive alternatives
What would they do if you did not exist? Include doing nothing, a spreadsheet,
pen and paper, an intern. ~40% of B2B deals are lost to "no decision," which
means these are the real competitors.

| Alternative | Who uses it | Why it is bad enough to switch from |
|---|---|---|
| | | |

## 2. Unique attributes
Capabilities the alternatives genuinely lack. Features first.

| Attribute | Do alternatives have it? |
|---|---|
| | |

## 3. Value
Translate each attribute into delivered value.

| Attribute | → Value | Who cares urgently |
|---|---|---|
| | | |

## 4. Best-fit segment
Specific enough to feel uncomfortably narrow. Name the trigger event that makes
them start looking.

Segment: ______
Trigger: ______

## 5. Market category
The context that sets buyer assumptions about competitors, pricing, and features.

Category: ______
Enter existing / create new: ______ (default: enter existing)
If crowded, the true sub-category where you are obviously first: ______

## 6. Trend (optional)
A shift making this urgent now. Only if genuinely true; a forced trend reads as
marketing.

## Tests — run all four

| Test | Pass? |
|---|---|

| **Portability** — could this sentence describe a competitor unchanged? (must FAIL) | |
| **Alternative** — does it beat "do nothing" explicitly? | |

## Final statement

> For [segment] who [trigger], [name] is a [category] that [unique value].
> Unlike [alternative], it [key differentiator].
