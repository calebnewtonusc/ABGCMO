# The one-page growth dashboard

Six numbers. If you cannot fit it on one page, you are measuring to feel busy.

## The rule for inclusion

**Would this number moving tell you to do something different?** If not, it is a
scoreboard, not an instrument. Cut it.

## The six

| # | Metric | Why | Benchmark |
|---|---|---|---|
| 1 | **North Star** | The one number capturing delivered value | Pick from the binding AARRR stage |
| 2 | **Activation rate** | Predicts revenue better than any other PLG metric | ~37.5% |
| 3 | **First-90-day cohort retention** | 60-70% of annual churn happens here | Compare cohort to cohort, never blended |
| 4 | **Time to value** | The control knob on activation | ~36 h median; under 5 min gives +40% 30-day retention |
| 5 | **The one channel number** | Whatever your single active channel produces | See `data/channel-economics.md` |
| 6 | **Net revenue retention** | Whether existing customers grow | 110-130% is top-performer |

## Cohort table — the only view that tells the truth

Blended churn mixes your best customers from three years ago with last month's
wrong-fit signups. It describes the average and represents nobody.

| Signup month | M1 | M3 | M6 | M12 |
|---|---|---|---|---|
| Jan | | | | |
| Feb | | | | |
| Mar | | | | |

**Read down the columns, not across the rows.** Later cohorts should outperform
earlier ones at the same age. If March at M3 is worse than January at M3, you are
acquiring worse-fit users, and that is an acquisition problem wearing a retention
costume.

## Vanity vs. real

| Vanity | Real |
|---|---|
| Stars | Forks, issues, returning contributors |
| Followers | Profile visits per week |
| Impressions | Dwell time, saves, bookmarks |
| Signups | Activation rate |
| Subscribers | Open rate by cohort, replies |
| Traffic | Traffic that activates |

## Attribution, honestly

Most attribution is a guess dressed as data. Two things you can trust:

1. **GitHub Insights → Traffic** — actual referring sites
2. **One question at signup**: "How did you hear about us?" Free text beats most
   tooling at this stage.

A concentrated launch destroys attribution. That is a real cost, and velocity is
usually worth more than knowing which of five channels did it.
