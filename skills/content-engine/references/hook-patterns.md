# Hook patterns

The hook determines most of a post's outcome. These are the four that work for
technical and business audiences, each with a real example from this repo's own
research so you can see the shape.

## 1. Contrarian correction

Received wisdom, then the evidence against it. Strongest pattern available,
because it is useful and disagreeable at once.

> Every guide tells you to use the "Show HN" tag.
> The only controlled study found no significant effect: β = −119.2, p = 0.39.

**Requires:** you are actually right, and can show it. Being wrong here is worse
than being boring.

## 2. Surprising specific number

> A GitHub "report" on X is weighted −369. A like is 0.5.
> One report cancels roughly 27 replies.

**Requires:** the number is sourced and checkable.

## 3. Named frustration

The reader thinks "I thought that was just me."

> Your README is 900 lines and the star decision happens in 15 seconds.
> The table of contents is where the demo should be.

## 4. Reference material

Lists and data get bookmarked, and bookmarks compound.

> The actual X ranking weights, read from the source repo rather than a blog —
> including the 150x signal that no growth guide mentions.

## Anti-patterns

| Do not write | Because |
|---|---|
| "I built X" | An ad. Asks for attention, offers nothing. |
| "Excited to announce" | Nobody is excited on your behalf. |
| "Here's the thing" / "Let me be clear" | Throat-clearing. Open on the point. |
| "It's not X, it's Y" | Just state Y. |
| "What nobody tells you" | Flatters the writer. Make the claim stand alone. |
| A closing aphorism | End on the last concrete point or the next action. |

## The portability test

If a sentence could move unchanged to someone else's post about a different
thing, it is filler. Cut it or make it true only here.

## Structure

1. **Hook** — stops the scroll
2. **Context** — one or two lines of stakes
3. **Body** — one idea per unit
4. **Close** — the concrete point or the next action

## Where the link goes

| Platform | Link placement |
|---|---|
| X | First self-reply. Never the main post. |
| LinkedIn | Nowhere. Not the body, and **not the first comment** — that is penalized now. |
| Reddit | In the body, never the title |
| Hacker News | The submission IS the link. Point at the repo. |
