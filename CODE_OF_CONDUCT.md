# Code of conduct

## The standard

Be straight and be kind. Those are compatible.

This repo is about evidence quality, so the interesting conversations here are
disagreements about whether a claim is true. Those are welcome and are the point.

## Expected

- **Argue with the claim, not the person.** "This number has no primary source" is
  the right shape. "You clearly didn't research this" is not.
- **Bring a source.** A correction with a better citation gets merged. A correction
  without one gets a request for one.
- **Say when you are uncertain.** "I think this is wrong because X, but I have not
  verified Y" is more useful than false confidence, and this repo has a whole tier
  system built on that distinction.
- **Accept being wrong gracefully.** The maintainer has publicly documented 189
  defects in his own work; nobody here has standing to be defensive.

## Not acceptable

Harassment, personal attacks, demeaning comments, or unwelcome attention of any
kind. Publishing others' private information. Deliberately posting claims you know
to be unsourced in order to game the repo's credibility.

## Enforcement

Report to the maintainer via a GitHub issue or private vulnerability report.
Reports will be handled discreetly. The maintainer may remove comments, close
threads, or block accounts for behavior that violates this document.

## Scope

Applies in this repository's issues, pull requests, and discussions, and when
representing the project publicly.
