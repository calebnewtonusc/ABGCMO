description: Fix how something is described using April Dunford's process
---

Work through positioning for $ARGUMENTS using `skills/positioning`.

1. **Competitive alternatives** — what would this person do if it did not exist?
   Include doing nothing, spreadsheets, and manual work. Those are usually the
   real alternative.
2. **Unique attributes** the alternatives genuinely lack
3. **The value** only you deliver, that someone actually cares about
4. **Who cares most** — specific enough to feel uncomfortably narrow
5. **Market category** that makes the value obvious

Then:
- Run the five-second test on the current description and say whether it passes
- Write the one-line version a user would repeat to a friend, in their words
- Run the portability test: would this sentence fit a competitor unchanged?
- If the category is crowded, find the true sub-category where this is obviously
  first, and lead with the attribute nobody else has

If the user's own words are strong, keep them. Do not rewrite someone's voice into
marketing copy.
